# 계산기 앱 요청

# 개발 스택
node js + electron + html + css 기반으로 앱을 구현한다.

# 주요 기능

앱 화면에 0부터 9까지 숫자 버튼과 사칙연산(+, -, *, /) 버튼, 등호(=) 버튼, 초기화(C) 버튼이 있어야 한다.
숫자 버튼을 누르면 현재 입력 중인 값이 화면 상단의 디스플레이에 표시되어야 한다.
두 숫자와 연산자를 입력하고 등호를 누르면 계산 결과가 디스플레이에 표시되어야 한다.
0으로 나누면 결과 대신 "Error"가 표시되어야 한다.
초기화 버튼을 누르면 디스플레이가 0으로 돌아가야 한다.
