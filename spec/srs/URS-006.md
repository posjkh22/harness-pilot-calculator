## 2. 기술 명세

### SRS-URS-006-01 (renderer/ui)

**명세**: 초기화 버튼 클릭 시 계산기의 표시 상태를 초기 표시값으로 되돌리고 display에 정확히 숫자 0을 표시해야 한다.

**근거**: 사용자가 표시된 입력값, 계산 결과 또는 Error를 기본 표시 상태로 되돌릴 수 있어야 한다.

| 항목 | 값 |
| --- | --- |
| 검증 대상 AC | AC-URS-006-01 |
| 검증 전략 | UI_INTEGRATION |
| 변경 예상 파일 | ui/calculator.js, tests/calculator.test.js, tests/calculator.ui.test.js |
| 테스트 훅 | Expose clear as data-testid="clear" and display as data-testid="display"., UI-test reset from a numeric value, a calculated result, and Error., Unit-test that reset removes stale expression state as well as setting display to 0. |

**인터페이스 계약**

| 유형 | 이름 | 방향 | 요청 | 응답 | 오류 | 권한 |
| --- | --- | --- | --- | --- | --- | --- |
| MODULE | calculatorState.reset | INTERNAL | No payload | State reset with display value "0" | Missing display element is reported as a renderer initialization error. | Renderer-local state transition. |
| EVENT | clear-click | INTERNAL | DOM click event from the clear button | Display text exactly "0" | Reset must not leave the prior numeric or Error display visible. | Renderer-local event only. |

**데이터 모델**

- Initial/reset displayValue: string "0".
- Reset clears the active expression state used for subsequent calculations.
- The acceptance contract observes the display value; internal state reset is included to prevent stale operands.

**오류 처리**

- Reset is deterministic and does not throw for any prior display state.
- If the display element is unavailable, initialization/test failure is surfaced rather than silently ignored.

**보안**

- Reset uses a fixed constant and does not process executable or HTML input.
- The handler remains renderer-local.

**성능·운영**

- Reset performs only in-memory state assignment and one display update.
- The display changes in the same click event cycle.

## 3. 보안 결정

| 설정 | 값 | 기본값 약화 | 근거 |
| --- | --- | --- | --- |
| reset behavior | renderer-local deterministic state reset | 아니오 | 권한 있는 API 없이 안전하게 초기화할 수 있다. |

## 4. 마이그레이션·호환성

- 신규 상태 모델이므로 기존 reset API 또는 저장 데이터와의 호환성 변경은 없다.
- clear 버튼 식별자와 초기 표시값 0을 자동화 계약으로 유지한다.

## 5. 구현 순서

1. 초기 상태와 reset transition을 정의한다.
2. clear 버튼에 reset handler를 연결한다.
3. display를 정확히 0으로 갱신한다.
4. 숫자, 계산 결과, Error 상태에서의 통합 테스트를 작성한다.

## 6. 위험·제외·미결정

**위험**

- URS-006의 수용 기준은 표시값을 명시하지만 내부 연산 상태 초기화 범위는 별도 결정이 필요하다.
- 후속 요구가 undo/history를 추가하면 단순 reset 모델을 확장해야 한다.

**제외 범위**

- 초기화 시 이력, 메모리, undo 상태를 보존하거나 복구하는 기능
- 초기화 후 추가 입력의 상세 UX
- 키보드 단축키

**미결정 사항**

- 초기화 이후 내부 계산 이력이나 메모리 기능을 유지할지 여부는 후속 요구에서 결정해야 한다.
