## 2. 기술 명세

### SRS-URS-002-01 (renderer/ui)

**명세**: 화면은 숫자 버튼 10개(0~9), 연산 버튼 4개(+,-,*,/), 등호 버튼 1개, 초기화 버튼 C 1개를 각각 표시해야 한다.

**근거**: 사용자가 요구된 계산기 조작을 수행할 수 있어야 한다.

| 항목 | 값 |
| --- | --- |
| 검증 대상 AC | AC-URS-002-01 |
| 검증 전략 | UI_INTEGRATION |
| 변경 예상 파일 | ui/index.html, ui/calculator.js, ui/styles.css |
| 테스트 훅 | 각 버튼에 고유 data-testid 또는 data-action 속성을 제공한다., 버튼 개수와 표시 텍스트를 DOM에서 조회한다. |

**인터페이스 계약**

| 유형 | 이름 | 방향 | 요청 | 응답 | 오류 | 권한 |
| --- | --- | --- | --- | --- | --- | --- |
| MODULE | ui/calculator.js | INTERNAL | DOM 버튼 클릭 이벤트 | 계산기 상태 갱신 및 display 렌더링 | 알 수 없는 버튼 식별자는 무시하고 오류를 기록한다. | 렌더러 DOM 접근 |

**데이터 모델**

- 숫자 버튼: 0~9
- 연산 버튼: +\|-\|*\|/
- 등호 버튼: =
- 초기화 버튼: C

**오류 처리**

- 필수 버튼이 DOM에 없으면 초기화 시 오류를 기록한다.
- 지원하지 않는 동작은 상태를 변경하지 않는다.

**보안**

- 버튼 동작은 사전 정의된 action과 허용된 값만 처리한다.
- 외부 입력이나 eval을 사용하지 않는다.

**성능·운영**

- 버튼 클릭 처리와 DOM 갱신은 입력 이벤트 안에서 완료한다.
