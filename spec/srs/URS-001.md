## 2. 기술 명세

### SRS-URS-001-01 (build)

**명세**: 애플리케이션은 Node.js 실행 환경과 Electron 데스크톱 런타임을 사용하며, renderer UI는 HTML과 CSS 파일로 구현해야 한다.

**근거**: 원본 요구조건이 구현 기술을 Node.js, Electron, HTML, CSS로 제한한다.

| 항목 | 값 |
| --- | --- |
| 검증 대상 AC | AC-URS-001-01 |
| 검증 전략 | ELECTRON_INTEGRATION |
| 변경 예상 파일 | package.json, electron/main.js, electron/preload.js, ui/index.html, ui/styles.css, ui/calculator.js, tests/calculator.test.js, tests/electron.integration.test.js |
| 테스트 훅 | Expose stable data-testid attributes for the display and every required button., Add a package review test that verifies Electron is configured and HTML/CSS assets exist., Launch the packaged window in an Electron integration test and assert it loads the local renderer. |

**인터페이스 계약**

| 유형 | 이름 | 방향 | 요청 | 응답 | 오류 | 권한 |
| --- | --- | --- | --- | --- | --- | --- |
| MODULE | electron/main.js | INTERNAL | Electron app lifecycle and BrowserWindow initialization | A running Electron application window loading the HTML renderer | Application startup failure must be surfaced to the process log. | Main-process-only lifecycle and window creation. |
| MODULE | ui/index.html | INTERNAL | Static HTML document containing calculator UI elements | Rendered calculator document | Malformed or missing document must fail the UI integration test. | Renderer DOM access only; no Node.js APIs. |

**데이터 모델**

- The implementation consists of JavaScript source, HTML markup, and CSS styles; no external persistence model is required.

**오류 처리**

- Startup and resource-loading errors are logged by the Electron main process and cause the integration test to fail.
- The renderer must not silently replace missing required UI elements.

**보안**

- BrowserWindow must use contextIsolation: true, nodeIntegration: false, and sandbox: true.
- Renderer code must use web APIs only and must not access Node.js or filesystem APIs directly.
- Only local packaged HTML resources are loaded.

**성능·운영**

- The initial window should load local resources without network requests.
- Calculator interactions should execute synchronously in the renderer for immediate feedback.

## 3. 보안 결정

| 설정 | 값 | 기본값 약화 | 근거 |
| --- | --- | --- | --- |
| contextIsolation | true | 아니오 | Renderer와 preload/main의 전역 실행 컨텍스트를 분리한다. |
| nodeIntegration | false | 아니오 | Renderer에서 Node.js API가 직접 사용되지 않도록 한다. |
| sandbox | true | 아니오 | Renderer 권한을 최소화하고 웹 콘텐츠 실행을 격리한다. |

## 4. 마이그레이션·호환성

- 신규 시스템이므로 기존 IPC, HTTP, 저장 포맷과의 호환성 변경은 없다.
- 신규 package.json에 정의된 Electron 실행 명령과 파일 경로를 최초 배포 산출물에 포함한다.

## 5. 구현 순서

1. package.json에 Electron 실행 스크립트와 개발 의존성을 정의한다.
2. main process에서 BrowserWindow를 생성하고 보안 기본값으로 ui/index.html을 로드한다.
3. HTML과 CSS로 계산기 화면 골격을 구현한다.
4. renderer JavaScript를 연결하고 Electron 통합 테스트로 기술 구성을 검증한다.
