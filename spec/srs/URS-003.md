숫자 버튼을 누르면 현재 입력 중인 값이 화면 상단 디스플레이에 표시된다.

| AC ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-URS-003-01 | 계산기 앱 화면이 표시되어 있고 입력값이 표시되는 디스플레이가 있을 때 | 사용자가 숫자 버튼을 1회 이상 누르면 | 누른 숫자를 포함한 현재 입력 중인 값이 화면 상단 디스플레이에 표시되어야 한다. |

## 2. 기술 명세

### SRS-URS-003-01 (renderer/ui)

**명세**: 숫자 버튼 클릭 시 renderer 상태의 현재 입력값에 해당 숫자를 반영하고, 화면 상단 display를 현재 입력 중인 값으로 즉시 갱신해야 한다.

**근거**: 사용자가 입력 중인 숫자를 확인할 수 있어야 한다.

| 항목 | 값 |
| --- | --- |
| 검증 대상 AC | AC-URS-003-01 |
| 검증 전략 | UI_INTEGRATION |
| 변경 예상 파일 | ui/index.html, ui/calculator.js, tests/calculator.test.js, tests/electron.integration.test.js |
| 테스트 훅 | Expose display as data-testid="display"., Unit-test one or more digit transitions and verify the resulting display string contains the pressed digit., UI-test clicking a digit button and reading the display text. |

**인터페이스 계약**

| 유형 | 이름 | 방향 | 요청 | 응답 | 오류 | 권한 |
| --- | --- | --- | --- | --- | --- | --- |
| MODULE | calculatorState.handleDigit | INTERNAL | digit: integer in the range 0..9 | Updated display string representing the current input | Non-integer or out-of-range digits are rejected without state mutation. | Renderer-local pure/state transition function. |
| EVENT | digit-click | INTERNAL | DOM click event from a digit button | Display text is updated to include the selected digit | Missing display element is reported as a test failure. | Renderer-local event only. |

**데이터 모델**

- displayValue: string, initialized to "0".
- currentInput: string, initialized to "0".
- Digits are appended according to the calculator input state; the exact multi-digit formatting remains implementation-defined unless constrained by the acceptance criterion.

**오류 처리**

- Invalid digit events are ignored with a development diagnostic and do not corrupt displayValue.
- A missing display element is surfaced as an initialization error.

**보안**

- Digit values originate from a fixed allowlist of button actions; arbitrary DOM text is not evaluated.
- Display updates use textContent rather than innerHTML.

**성능·운영**

- A digit click updates the display in one renderer event cycle.
- No disk or network operation occurs for numeric input.

## 3. 보안 결정

| 설정 | 값 | 기본값 약화 | 근거 |
| --- | --- | --- | --- |
| display rendering | textContent only | 아니오 | 사용자 입력을 HTML로 해석하지 않아 DOM injection 가능성을 줄인다. |

## 4. 마이그레이션·호환성

- 신규 renderer 상태이므로 기존 표시 포맷과의 호환성 변경은 없다.
- 표시 요소의 data-testid와 초기값 0을 테스트 계약으로 유지한다.

## 5. 구현 순서

1. 초기 display와 calculator state를 정의한다.
2. 숫자 버튼 입력 검증과 상태 전이를 구현한다.
3. display를 textContent로 갱신한다.
4. 단위 테스트와 Electron UI 통합 테스트를 추가한다.

## 6. 위험·제외·미결정

**위험**

- 여러 숫자 입력의 최대 자릿수와 표시 형식이 요구조건에서 정해지지 않아 후속 요구가 상태 모델에 영향을 줄 수 있다.
- 계산 결과 직후 숫자 입력의 동작은 별도 요구가 없어 명시하지 않는다.

**제외 범위**

- 여러 숫자 입력 시 최대 자릿수와 표시 형식
- 키보드 숫자 입력
- 소수점 입력

**미결정 사항**

- 계산 결과 직후 숫자 버튼을 누를 때 기존 결과에 이어 붙일지 새 입력으로 시작할지는 후속 요구에서 결정해야 한다.
