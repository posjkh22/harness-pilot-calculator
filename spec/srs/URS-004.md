## 1. 원본 사용자 요구사항 요약

두 피연산자와 하나의 사칙연산자로 계산한 결과를 표시한다.

| AC ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-URS-004-01 | 첫 번째 숫자 8과 덧셈 연산자와 두 번째 숫자 2가 입력되어 있다. | 사용자가 등호 버튼을 누른다. | 디스플레이에 10이 표시되어야 한다. |
| AC-URS-004-02 | 첫 번째 숫자 8과 뺄셈 연산자와 두 번째 숫자 2가 입력되어 있다. | 사용자가 등호 버튼을 누른다. | 디스플레이에 6이 표시되어야 한다. |
| AC-URS-004-03 | 첫 번째 숫자 8과 곱셈 연산자와 두 번째 숫자 2가 입력되어 있다. | 사용자가 등호 버튼을 누른다. | 디스플레이에 16이 표시되어야 한다. |
| AC-URS-004-04 | 첫 번째 숫자 8과 나눗셈 연산자와 두 번째 숫자 2가 입력되어 있다. | 사용자가 등호 버튼을 누른다. | 디스플레이에 4가 표시되어야 한다. |

## 2. 기술 명세

### SRS-URS-004-01 (renderer/ui)

**명세**: 첫 번째 숫자, 하나의 +\|-\|*\|/ 연산자, 두 번째 숫자 입력 후 =를 누르면 해당 연산의 결과를 display에 표시해야 한다.

**근거**: 네 가지 사칙연산 수용 기준을 동일한 계산 상태 모델로 충족한다.

| 항목 | 값 |
| --- | --- |
| 검증 대상 AC | AC-URS-004-01, AC-URS-004-02, AC-URS-004-03, AC-URS-004-04 |
| 검증 전략 | UI_INTEGRATION |
| 변경 예상 파일 | ui/calculator.js, tests/calculator.spec.js |
| 테스트 훅 | 순수 calculate 함수를 테스트 가능하게 export한다., UI 테스트에서 8, 연산자, 2, = 순서로 버튼을 클릭한다. |

**인터페이스 계약**

| 유형 | 이름 | 방향 | 요청 | 응답 | 오류 | 권한 |
| --- | --- | --- | --- | --- | --- | --- |
| MODULE | ui/calculator.js#calculate | INTERNAL | operand1: number, operator: '+'\|' -'\|'*'\|'/', operand2: number | 계산 결과 문자열 | 지원하지 않는 operator는 계산하지 않는다.; 숫자로 변환할 수 없는 피연산자는 오류 상태로 처리한다. | 렌더러 계산 상태 접근 |

**데이터 모델**

- firstOperand: 첫 번째 피연산자 문자열
- operator: 허용된 사칙연산자
- secondOperand/currentInput: 두 번째 피연산자 문자열
- result: 계산 결과 표시 문자열

**오류 처리**

- = 입력 시 두 피연산자와 연산자가 유효한 경우에만 계산한다.
- 지원하지 않는 연산 또는 불완전한 입력은 계산하지 않고 현재 상태를 유지한다.
- 계산 결과는 숫자 문자열로 표시한다.

**보안**

- 계산은 명시적인 연산자 분기문으로 구현한다.
- eval, Function 생성자 및 사용자 문자열 실행을 사용하지 않는다.

**성능·운영**

- 계산은 렌더러 내 상수 시간 산술 연산으로 처리한다.
- 서버나 파일 시스템을 사용하지 않는다.
