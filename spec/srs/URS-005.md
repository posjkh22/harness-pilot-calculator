## 1. 원본 사용자 요구사항 요약

제수가 0인 모든 나눗셈에서 결과 대신 Error를 표시한다.

| AC ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-URS-005-01 | 첫 번째 숫자 8, 나눗셈 연산자, 두 번째 숫자 0이 입력되어 있다. | 사용자가 등호 버튼을 누른다. | 디스플레이에 "Error"가 표시되어야 한다. |
| AC-URS-005-02 | 첫 번째 숫자 0, 나눗셈 연산자, 두 번째 숫자 0이 입력되어 있다. | 사용자가 등호 버튼을 누른다. | 디스플레이에 "Error"가 표시되어야 한다. |

## 2. 기술 명세

### SRS-URS-005-01 (renderer/ui)

**명세**: operator가 '/'이고 두 번째 피연산자가 숫자 0이면 피제수 값과 관계없이 display에 정확히 'Error'를 표시해야 한다.

**근거**: 8/0과 0/0을 포함한 모든 0 나누기 수용 기준을 보장한다.

| 항목 | 값 |
| --- | --- |
| 검증 대상 AC | AC-URS-005-01, AC-URS-005-02 |
| 검증 전략 | UI_INTEGRATION |
| 변경 예상 파일 | ui/calculator.js, tests/calculator.spec.js |
| 테스트 훅 | 8/0 및 0/0 UI 시나리오를 실행한다., display의 정확한 'Error' 텍스트를 검증한다. |

**인터페이스 계약**

| 유형 | 이름 | 방향 | 요청 | 응답 | 오류 | 권한 |
| --- | --- | --- | --- | --- | --- | --- |
| MODULE | ui/calculator.js#calculateDivisionByZero | INTERNAL | operand1: number, operator: '/', operand2: 0 | 문자열 'Error' | 0 나누기 조건에서는 Infinity, NaN 또는 예외를 표시하지 않는다. | 렌더러 계산 상태 접근 |

**데이터 모델**

- errorState: 'Error' 또는 null
- displayValue: 'Error' when divisor === 0

**오류 처리**

- 계산 전 제수의 수치가 0인지 검사한다.
- 0 나누기 시 오류 상태를 저장하고 display를 'Error'로 갱신한다.
- Error 상태에서 C를 누르면 정상 초기 상태로 복귀한다.

**보안**

- 오류 문자열은 고정 상수로 관리한다.
- Infinity 또는 NaN을 사용자 결과로 노출하지 않는다.

**성능·운영**

- 0 나누기 검사는 나눗셈 수행 전에 즉시 실행한다.
