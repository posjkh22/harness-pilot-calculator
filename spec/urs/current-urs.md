### URS-005 0으로 나누기 오류 표시

| 항목 | 값 |
| --- | --- |
| 변경 구분 | 변경 |
| 상태 | ACTIVE |
| 유형 | 기능 |
| 우선순위 | MUST |
| 행위자 | 계산기 사용자 |
| 원문 근거 | SRC-001:L11-L11 |

**설명**: 제수가 0인 나누기 계산을 실행하면 피제수가 0인지 여부와 관계없이 계산 결과 대신 디스플레이에 정확히 "Error"를 표시해야 한다.

**변경 사유**: 심사자 지시에 따라 피제수가 0이 아닌 경우라는 제한을 제거하고, 0 ÷ 0을 포함한 제수가 0인 모든 나누기 계산에 오류 표시를 적용함

**트리거**: 사용자가 등호 버튼을 눌러 제수가 0인 나누기 계산을 실행한다.

**사전 조건**

- 계산기 앱 화면이 표시되어 있다.
- 사용자가 임의의 피제수, 나누기 연산자, 숫자 0을 순서대로 입력했다.

**주 흐름**

1. 사용자가 임의의 피제수를 입력한다.
2. 사용자가 나누기 연산자를 입력한다.
3. 사용자가 제수로 숫자 0을 입력한다.
4. 사용자가 등호 버튼을 누른다.
5. 앱은 계산 결과 대신 디스플레이에 "Error"를 표시한다.

**대체·예외 흐름**

-

**사후 조건**

- 디스플레이에 계산 결과가 아닌 "Error"가 표시된다.

**수용 기준**

| AC ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-URS-005-01 | 피제수가 0 또는 0이 아닌 값이고 나누기 연산자와 제수 0이 입력되어 있을 때 | 사용자가 등호 버튼을 누르면 | 피제수가 0인 0 ÷ 0을 포함하여 제수가 0인 모든 계산에서 디스플레이에 정확히 "Error"가 표시되고 숫자 계산 결과는 표시되지 않아야 한다. |

**가정**

-

**범위 제외**

- 0으로 나누기 이후의 추가 입력 동작 및 오류 해제 방식
